# editorial-mono の抽出元

このプロファイルは特定サイトの複製ではなく、以下のデザイン系譜から「際立つ特徴」を抽出して構成した同梱の実例。
実運用では `extract` が渡された参照 URL/画像をここに記録する。

- スイス・タイポグラフィ(国際タイポグラフィ様式): 左揃え・グリッド・サンセリフ規律 → Layout grammar, 数字の扱い
- 編集デザイン(雑誌の誌面組版): セリフ見出し × サンセリフ本文の対比、リード文の言い切り → Typography, Copy tone
- 温かい紙色 + 単一の朱赤アクセント: 色数を絞る方針 → Palette
- 「面は影でなく罫線で分ける」原則: グラフィックデザインの古典的な面分割 → Decoration

> 注: 機密案件の参照素材・スクショはこのリポに置かない(public 同期されるため)。色や書体の観察メモのみ残す。
