# dev-log (私的・ローカル専用)

AI 開発の会話 craft (説明・依頼・調整・設計/テストの作り込み) を蒸留した dev-log の保管場所。`/devlog` が書き込む。

**このディレクトリの中身は gitignore・ローカル専用**。transcript (`~/.claude/projects/**/*.jsonl`) 由来で顧客案件の内容を含みうるため public に出さない (jooi の教訓と同型)。公開してよいのは、抽象化・スクラブした craft パターンを **agent-rules へ昇格したものだけ**。

標準: [`docs/design/devlog-standard.md`](../docs/design/devlog-standard.md) / 根拠: [`ADR-0016`](../docs/adr/0016-devlog-knowledge-capture.md)。
