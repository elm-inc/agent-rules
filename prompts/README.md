# Prompts

コピペで使える Claude Code 用プロンプトテンプレート集。スキルと違ってこちらは **人間がそのまま貼り付けて使う** 想定。

## 索引

| ファイル | 用途 |
|---|---|
| [docs-visualize.md](docs-visualize.md) | 新プロジェクトでアーキテクチャを可視化したいとき |
| [mac-verification.md](mac-verification.md) | iOS プロジェクトを Mac で実機ビルド + 動作確認するとき |

## スキルとの違い

| | スキル (`skills/`) | プロンプト (`prompts/`) |
|---|---|---|
| 主な利用者 | Claude (自動 invoke) | 人間 (手動コピペ) |
| 形式 | YAML frontmatter + 指示 | プレーンな日本語 |
| 役割 | Claude の振る舞い定義 | 人間 ↔ Claude の最初の一言 |

スキルが完備されているなら自然言語でも動くが、明示プロンプトは:
- 期待出力の予測が立てやすい
- 別プロジェクトのオンボーディング時に新人にも渡せる
- スキル description のキーワードに依存しない確実な起動

…という点で価値がある。

## 改善

良いプロンプトが見つかったらここに追加 (PR ベース)。実プロジェクトで使って手応えのあった文面を反映する。
